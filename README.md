# Multiplayer FPS 2.0: test builds

Downloads for the test builds. The game code is not in this repo.

## How to play

1. Go to the [latest release](../../releases/latest) and download **GameLauncher.exe**.
2. Put it in **its own folder** (the game installs next to it, about 600 MB) and start it.
3. Windows may say "Windows protected your PC" because the launcher is not signed: click **More info**, then **Run anyway**. Only the first time.
4. The launcher installs the game and keeps it (and itself) up to date. Click **Play**.

Nothing else to install.

## Problems?

In the launcher: **Settings > Open logs** and send the files to the developer. **Settings > Repair** downloads the game again.
